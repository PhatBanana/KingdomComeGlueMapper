# KingdomComeGlueMapper Setup 0.3.15

This prerelease fixes population conversion failing with “No such file or
directory” when generated character texture paths exceed Windows' normal path
limit. It also adds the separate experimental **KCD1:MP** setup option.

## Changes

- Use Windows extended filesystem paths throughout population staging,
  packaging and cleanup. No registry change or shorter build folder is needed.
- Add a long-path regression check to the packaged setup self-test.
- Add KCD1:MP export from a completed KCD1 Map, retaining its lighting and
  shader outputs. Selecting both map options builds the world first using the
  normal shared cache, then exports the multiplayer profile.
- Provide a dedicated multiplayer screen with Map source, Client, Server
  settings and Launch panels, styled consistently with the setup UI.
- Configure server name, port, player limit, password, PvP, world time and
  time speed. Save profiles, start/stop an owned server, join or launch an
  offline test, and restore the previous single-player mod order.
- Copy validated KCD:MP 0.44.0 client/server distributions into the profile so
  temporary download directories are no longer required after export.
- Include the current shared lighting/shader cache and older-build cache
  import workflow, plus the previously committed generic quest and population
  conversion work. See the source history for those changes.

## Validation and limits

The exact character that triggered the reported failure (`ska_ales`) was
reconverted successfully with a 287-character texture path and its assets
packaged. The Windows executable's self-test also exercises writing, traversing,
archiving, renaming and cleaning up paths longer than 260 characters.

Automated checks cover population staging, setup/resume/cache handling,
multiplayer export, activation/restoration, settings, launch arguments and
the rendered settings UI. A complete fresh map build has not been rerun for
this release, and multiplayer player initialization and two-client gameplay
remain unverified.

KCD1:MP is a scenery export for KCD:MP 0.44.0 and Steam KCD2 1.5.6. It removes
campaign startup, NPC schedules and animal spawners; it does not make the
campaign cooperative. Hosting requires .NET 10 x64. Each client needs the same
converted world. Read the [multiplayer setup guide](../kcd1-mp-setup.md).

## Retrying the failed population build

Close the previous setup window and open this executable. Choose **Activity →
Resume failed setup…** and select the original job folder containing `job.json`.
Logs, outputs and cache entries are retained. If no complete map package was
verified before the failure, map conversion restarts; matching lighting and
shader caches remain reusable.

Download the Windows setup executable and `SHA256SUMS.txt` from the release.
The setup does not bundle game content or the KCD:MP runtime distributions.
