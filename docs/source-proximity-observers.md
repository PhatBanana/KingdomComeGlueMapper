# Source proximity speech in setup

Recipe 22 connects the existing proximity-observer converter to clean setup and
saved-package migration. Previously the approach dialogues and recordings were
packaged, but the observer that requests them was only available in a standalone
test builder. Ordinary ambient greetings are a separate native system.

The upgrader discovers objective-gated distance observers in each imported
quest's source controller. It accepts the converter's supported control flow,
resolves the speaker from the source topic/role/soul relationships, and requires
the requested monologue aliases to exist in the package. It imports source
distances and delays, retains enclosing objective conditions, and uses a stable
observer identity so applying the upgrade twice does not duplicate triggers.

The opening father observer is supported: five-second initial delay, ten-metre
entry range, five-metre approach call, eleven-metre leaving call, five-second
repeat waits and forty-metre termination range, gated by the original objective
states. These values are read from the source, not embedded in setup.

The receipt lists unsupported observers explicitly. The later nails-for-Theresa
loop and speech outside this supported objective-observer shape still require
additional control-flow adapters. Native greeting parameter errors are also
independent of this source observer conversion.

Runtime verification requires a fresh New Game before the speak-with-father
objective starts. Retrofitting timers into a save where that objective already
started has not been validated. Package migration alone is not playback proof.
